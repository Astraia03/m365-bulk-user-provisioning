# 管理センター 匯入 CSV 格式

## 取得正確表頭（最保險）
先從管理センター下載**官方空白模板**：`複数のユーザーの追加` → CSV 模式 → 下載模板。
**表頭語言 = 管理センター的介面語言**，所以不要憑記憶寫欄位名。

## 日文介面的表頭（實測，2026-09）

```
ユーザー名,名,姓,表示名,役職,部署,事業所番号,職場の電話,携帯電話,FAX,連絡用メール アドレス,住所,市区町村,都道府県,郵便番号,国または地域
```

| 欄位 | 注意事項 |
|---|---|
| `ユーザー名` | **完整 UPN**（`alias@domain`），不是裸 alias |
| `名` / `姓` | 分開；`表示名` 是顯示名稱 |
| `役職` / `部署` | 職稱／部門 |
| `事業所番号` | 據點代碼（可留空） |
| `国または地域` | **當地語系標籤**，見下 |
| 其他 | 可留空 |

## 國別標籤必須用當地語系名稱
實測：台灣是 **`台湾`**（不是 `Taiwan`、不是 `TW`）。

查證方法——在管理センター的 console 執行：

```js
window.m365config.supportCentralConfig.SupportedRegions
```

回傳清單裡每個地區都有各語言的標籤，挑當前介面語言的那個。

## 檔案編碼
- **UTF-8 with BOM + CRLF**（官方模板就是這樣，Excel 與管理センター都吃）
- `scripts/build_import_csv.py` 已處理

## 上傳與送出（自動化時）
1. 進入 `#/addmultipleusers` → 選 CSV 模式
2. 掛檔：若用 CDP，`DOM.setFileInputFiles` **不會觸發前端框架的 onChange**，
   必須補：
   ```js
   input.dispatchEvent(new Event('change', { bubbles: true }))
   ```
   否則「次へ」會說沒有檔案。
3. 按「次へ」→ 確認解析結果（**人數**與**地點**是否自動帶入）
4. 勾授權 → 確認頁 → 執行（25 人約需 1 分鐘）
5. **完成後下載含臨時密碼的明細**，立刻 `chmod 600`

## 驗證
- 使用者清單的總數 = 既有 + 新增
- 授權頁的 `割り当て済み / 總數` = 需求數量
- 抽查 1–2 筆詳細資料（姓名、表示名、部署、国）
